# Pilot Coding Rubric Public-Minimum Template

> **Status: public template only; not a final codebook, pre-registration, or
> freeze.** Classification boundaries, examples, counterexamples, opportunity
> mappings, pilot-observation mappings, and the seeded-control answer key remain
> in an exact external private artifact. Only its SHA-256 reference or
> nonce-protected commitment is public.

This template is an instrument-testing contract, not the reserved release
rule. It assigns no severity, core status, weight, threshold, denominator,
repetition unit, or real-reader pass/fail result.

## 1. Public target set

The private rubric must explicitly code each already-ratified target in every
admissible session:

| Target ID | Public description |
| --- | --- |
| `RE-TGT-ORDINARY-LIFE` | ordinary constructive life |
| `RE-TGT-DEMOCRATIC-CHOICE` | democratic choice |
| `RE-TGT-PRIVATE-FREEDOM` | private freedom |
| `RE-TGT-SUCCESSFUL-PROVISION` | successful provision |
| `RE-TGT-REPAIR` | repair |
| `RE-TGT-PRISONER-STRESS-TEST` | the prisoner as a stress test rather than the central inhabitant |

The private codebook also covers normal public functions, response-stage
distinctions, Book 2 dependencies, external assumptions, and model limits as
instrument observations. It must not silently add those observations to the
canonical target set or treat them as a release taxonomy.

## 2. Public state vocabulary

Target outcomes use `identified`, `not-identified`, `missing`, `ambiguous`,
`multiply-coded`, or `unclassified`. Pilot misconception observations use
`present`, `absent`, `missing`, `ambiguous`, `multiply-coded`, or
`unclassified`. Adjudication uses `not-required`, `resolved`, or `unresolved`.

The private codebook defines exact semantic boundaries for those states,
including how excerpts, cross-prompt statements, occurrence/opportunity raw
metadata, and genuine non-response are handled. It maps no state to a release
verdict. The later author ruling alone chooses missing, ambiguity,
adjudication, denominator, and evaluability policies.

## 3. Independence and adjudication minimum

- Coder A and coder B receive identical opaque unaided records without
  identity, demographics, accessibility details, recruitment source,
  compensation, diagnostic feedback, or facilitator opinion.
- Each codes independently and cites the smallest supporting excerpt in the
  private record.
- The custodian locks both initial records before either coder sees the other.
- The separate adjudicator applies only the frozen private codebook and records
  either a resolved final state or an unresolved rubric defect.
- Nobody selects the more favourable code, changes a boundary after seeing the
  distribution, or asks a participant to repair an answer.

Raw excerpts, rationales, coder identities, disagreements, and the exact
codebook stay private. The public record may contain only the canonical coded
outcomes, digests, coded deviations, and identity-free custody attestations.

## 4. Admissibility remains orthogonal

The reviewer/custodian, not the content coders, classifies a session as
`admissible`, `inadmissible`, or `withdrawn` from the frozen ethics and
protocol record. Inadmissible or withdrawn sessions publish no content
outcomes. No favourable answer cures a consent, compensation, accessibility,
role, data, safety, or protocol breach.

## 5. Private codebook completeness

Before freeze, the reviewer/custodian must attest that the exact private
codebook contains:

- complete identification and contradiction boundaries for every public
  target;
- complete, provisionally named pilot-observation boundaries with no severity
  or core mapping;
- mutually discriminating examples and counterexamples not drawn from pilot
  participants;
- treatment instructions for every public state and adjudication state;
- raw occurrence/opportunity recording instructions kept distinct from the
  later release denominator and repetition unit;
- a private mapping from every committed seeded plant to its expected
  observation; and
- a version, canonical encoding, SHA-256, freeze time, and custody provenance.

The public attestation checks completeness and binding, not the private
artifact's truth or quality.
