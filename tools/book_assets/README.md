# Book rendering assets

`NotoSerifTamil.ttf` is the unmodified variable Noto Serif Tamil font from
[Google Fonts](https://github.com/google/fonts/tree/main/ofl/notoseriftamil).
Its upstream filename is `NotoSerifTamil[wdth,wght].ttf`. It was retrieved on
2026-09-19 to render the Tamil epigraph without relying on a reader's installed
fonts. Copyright 2022 The Noto Project Authors.

The font is licensed under the SIL Open Font License 1.1, reproduced in
[OFL-NotoSerifTamil.txt](OFL-NotoSerifTamil.txt). Those terms govern the font;
the book's prose and the build scripts retain their separate licences.
